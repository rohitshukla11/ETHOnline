READ THIS BEFORE QUOTING THE ABOVE
==================================
Run B STILL APPROVES, at the same LTV and the same principal. 873 still clears
the 850 threshold for the 22000bps band, so losing 20 points of land-tenure
contribution does not change the outcome for this applicant.

So the accurate claim is: the score moves, the provenance is declared, and
nothing downstream can mistake a degraded score for a live one.

The claim it does NOT support: that the system refuses to lend on incomplete
data. It does not. Whether an unavailable bureau SHOULD block approval is a
policy question - see docs/chainlink-feedback.md. For a marginal applicant
sitting near a band boundary, those 20 points would flip the decision, and the
flag is what tells you which side of that line the score came from.
